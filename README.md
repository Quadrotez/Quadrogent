# Quadrogent

Автономный AI-агент с локальным LLM, Docker-песочницей и постоянной памятью.

## Возможности

- **Три режима**: Auto (умный выбор), Work (выполнение задач в Docker), Talk (обычный чат)
- **Docker-песочница**: изолированный Ubuntu 22.04, Python, git, curl, zip — всё готово к работе
- **Постоянная память**: агент сам решает, что важно запомнить и сохраняет это автоматически
- **Кастомные системные промпты**: переопределяйте промпты для каждого режима в настройках
- **Аватарки**: логотип приложения у агента, ваша фотография — у вас (настраивается)
- **Анимация думания**: мигающая анимация во время генерации
- **Экспорт чатов**: HTML / TXT / JSON / Dev Logs
- **История памяти**: просматривайте, редактируйте и удаляйте отдельные воспоминания

## Требования

- Python 3.11+
- Docker Desktop (запущенный)
- [LM Studio](https://lmstudio.ai/) с загруженной моделью и включённым сервером

## Установка

```bash
pip install -r requirements.txt
python main.py
```

## Настройки

Откройте **⚙ Настройки** в нижней части боковой панели:

| Вкладка | Что там |
|---|---|
| Подключение | URL LM Studio, температура |
| Промпты | Кастомные системные промпты для Auto / Work / Talk |
| Профиль | Установить/сменить аватарку пользователя |
| Память | Просмотр, редактирование и удаление отдельных воспоминаний |

## Как работает авто-память

После каждого завершённого обмена сообщениями агент запускает фоновую проверку:
задаёт модели вопрос «стоит ли это запомнить?» и, если да, автоматически сохраняет
краткое резюме в долгосрочную память. Всё сохранённое доступно во вкладке **Память**.

## Workspace

Папка `workspace/` монтируется в Docker как `/workspace`. Все файлы, созданные агентом,
появляются там. Кнопка **🗑 Очистить workspace** удаляет файлы как внутри контейнера,
так и на хосте, обходя возможные проблемы с правами монтирования.
