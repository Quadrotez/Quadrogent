# 🤖 Quadrogent

**Open-source AI agent for coding, conversations, and complex tasks.**

Quadrogent — локальный ИИ-агент с минималистичным интерфейсом, Docker-песочницей для выполнения кода и встроенным веб-поиском. Работает с локальными моделями через LM Studio.

## Возможности

- **Два режима работы**: Work (автономное выполнение задач) и Talk (диалог)
- **Docker-песочница**: изолированное выполнение команд Linux с root-правами
- **Веб-поиск**: встроенный поиск информации в интернете
- **Управление файлами**: загрузка, редактирование, отправка файлов
- **Память**: сохранение контекста между сессиями для постоянных чатов
- **История чатов**: полное сохранение всех диалогов в SQLite

## Стек

- **Python 3.10+**
- **PyQt5** — интерфейс
- **SQLite3** — хранение данных
- **Docker** — песочница для агента
- **LM Studio** — локальная модель (порт 1234)

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск LM Studio

Запустите LM Studio и активируйте локальный сервер на порту `1234`.

### 3. Запуск Docker

Убедитесь, что Docker установлен и запущен:

```bash
docker --version
```

### 4. Запуск Quadrogent

```bash
python main.py
```

## Режимы работы

| Режим | Описание |
|-------|----------|
| **Work** | Агент составляет план, выполняет задачи автономно, использует инструменты |
| **Talk** | Обычный диалог без вызова инструментов |
| **Auto** | Агент сам решает, какой режим использовать |

## Настройки чата

- **Постоянный** — при завершении сохраняется ключевая мысль диалога в память
- **Временный** — обычный чат без сохранения в память
