```python
# generate_files.py

import random

def generate_random_numbers(num_files, numbers_per_file):
    for i in range(1, num_files + 1):
        filename = f"file_{i}.txt"
        with open(filename, "w") as file:
            for _ in range(numbers_per_file):
                file.write(f"{random.randint(0, 100)}\n")

generate_random_numbers(100, 10)
```

Теперь запишем этот скрипт в файл `generate_files.py` в директорию `/workspace/uploads`.
